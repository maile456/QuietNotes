这是一个真实的笔记服务吗？

这是 QuietNotes 风格 skill 附带的原创前端示例。首页中的新建笔记、搜索、设备预览与主题选择可以直接体验；阅读空间提供文章、分类、搜索和收藏。

新建的笔记会保存在哪里？

首页创建的笔记仅保存在当前浏览器的本地存储中，不会上传到服务器，也不会自动同步到其他设备。清除浏览器网站数据会移除这些笔记。

手机和平板也能使用吗？

可以。首页和阅读空间会适应不同屏幕大小。首屏的电脑、手机和平板选项用于切换同一份内容的预览布局，不代表独立的原生应用。
